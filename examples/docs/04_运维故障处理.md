# 运维故障处理手册

本手册面向 FE_HEART 一线运维人员，覆盖分机注册失败、呼叫无声音、中继全忙和媒体单板告警四类高频故障。排查遵循“先看告警、再看日志、最后改配置”的顺序，避免盲目重启。

## 1. 分机注册失败

**现象**：分机启动后显示“注册超时”，FE_HEART 在线用户表中没有该分机。

**排查步骤**：

1. 在分机侧确认注册服务器地址和端口是否为 FE_HEART 的接入地址。
2. 在接入网关执行 `display sip register`，查看最近的 REGISTER 请求和失败原因码。
3. 检查分机密码是否与用户表一致；401/403 通常表示认证失败。
4. 检查防火墙是否放通 UDP 5060 和 RTP 端口段 30000-30100。
5. 若分机位于 NAT 后，确认开启 NAT 穿越并配置外网映射地址。

**常见原因**：密码错误、注册地址配置错误、防火墙拦截、分机号段未在号码分析表中登记。

## 2. 呼叫无声音

**现象**：呼叫可以接通，但双方听不到声音。

**排查步骤**：

1. 执行 `show call all` 确认呼叫的媒体地址和端口是否正常分配。
2. 检查 SD5993 单板的媒体资源占用率，执行 `display media slot 3`。
3. 抓包确认 RTP 是否双向到达，重点检查 NAT 场景下的 SDP 地址。
4. 确认编解码协商结果，必要时临时锁定 G.711 排除转码问题。

## 3. 中继全忙

**现象**：分机呼叫外线时听到忙音，日志出现 `TRUNK_BUSY`。

**排查步骤**：

1. 执行 `display trunk group` 查看各中继组的占用数和可用数。
2. 确认是否存在异常挂死的中继；必要时执行 `reset trunk`。
3. 检查中继组的主备配置和负荷分担策略是否合理。
4. 若长期超负荷，评估扩容中继或增加中继组。

## 4. 媒体单板告警

**现象**：网管出现 `MEDIA_BOARD_ALM`，单板 ALM 红灯亮。

**排查步骤**：

1. 执行 `display board 3` 查看温度、电源和端口状态。
2. 检查风扇和机框散热，温度超过 65℃ 会触发降额。
3. 若单板无法上线，执行 `reset board slot 3`，仍失败则更换单板。
4. 更换后执行 `display board` 核对序列号，并观察 30 分钟确认告警不再复发。

## 5. 升级与回滚

版本升级前必须备份号码分析表、中继组配置和用户数据。升级失败时按发布说明回滚到上一版本，回滚后执行 `display version` 和 `show call all` 验证业务恢复。
