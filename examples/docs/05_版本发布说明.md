# FE_HEART v2.3.0 版本发布说明

发布日期：2026-06-18　　适用版本：v2.2.x 升级至 v2.3.0　　升级方式：滚动升级

## 1. 版本概述

v2.3.0 聚焦分组转发性能、SD5993 媒体资源调度和运维可观测性三个方向，新增号码分析热加载、中继组自动倒换和媒体资源看板三项能力，并修复了 7 个已知问题。

## 2. 新增特性

| 特性 | 说明 | 受益场景 |
| --- | --- | --- |
| 号码分析热加载 | 修改号码分析表后 5 秒内生效，无需重启呼叫控制 | 分支频繁调整号码前缀 |
| 中继组自动倒换 | 主用中继组故障时自动切换到备用组，切换时间小于 3 秒 | 中继链路故障 |
| 媒体资源看板 | 实时展示 SD5993 各槽位资源占用与告警 | 容量规划与故障定位 |
| FE_HEART_Start 参数校验 | 启动时校验 instance、trunk_group 等参数，错误配置提前拦截 | 减少启动失败 |

## 3. 改进与修复

- 优化 1000 路并发下的呼叫建立时延，P95 从 240 ms 降至 190 ms。
- 修复 SD5993 单板复位后媒体资源未释放的问题。
- 修复 NAT 场景下 SDP 地址未替换导致单通的问题。
- 修复中继组负荷分担在成员数量变化后不重新计算的问题。

## 4. 升级注意事项

1. 升级前执行 `display version` 记录当前版本，并备份配置。
2. 先升级备用节点，验证业务正常后再升级主用节点。
3. 升级完成后执行 `display board`、`show call all` 和 `display trunk group` 检查业务状态。
4. 如需回滚，使用上一版本安装包并恢复配置备份。
