## DSH Web 应用图标

- `dsh-web-icon.png`（128×128）与 `dsh-web-favicon.png`（32×32）提取自本机桌面应用 `DSH Web.app/Contents/Resources/AppIcon.icns`。
- 使用 macOS `iconutil` 提取图标包内已有的 PNG 图层，未重新绘制或改动像素。
- `favicon.ico` 封装同一图标包已有的 32/64/128 像素 PNG；兼容入口 `favicon.svg` 内嵌相同的 128 像素图像。均不重新绘制图标。
